DualStream HLS — واجهة Cloudflare + تشغيل FFmpeg محليًا
=======================================================

الموقع:
https://ds.aymanalboqami.workers.dev/

الهدف من هذه النسخة:
- إعداد مرة واحدة فقط عبر Install_Agent_Autostart.bat.
- بعدها يبدأ المساعد المحلي بصمت عند تسجيل الدخول إلى Windows.
- الاستخدام اليومي من واجهة الموقع فقط؛ لا حاجة لفتح BAT كل مرة.
- FFmpeg نفسه لا يبدأ إلا عند الضغط على تشغيل البث من الواجهة.

الإعداد لمرة واحدة:
1) فك ضغط الحزمة في مجلد ثابت لا تنقله لاحقًا.
2) شغّل Install_Agent_Autostart.bat مرة واحدة.
3) افتح موقع Cloudflare من المفضلة. بعد تسجيل الدخول القادم إلى Windows سيبدأ المساعد تلقائيًا.
4) لاستخدامه فورًا بعد الإعداد، ينتظر ملف التثبيت ثانيتين ويحاول تشغيل المهمة مباشرة.

الملفات المهمة:
- DualStream_Local_Agent.py: المساعد المحلي الذي يتحكم في FFmpeg ويقدم HLS على 127.0.0.1:8765.
- Install_Agent_Autostart.bat: تثبيت مهمة Windows لتشغيل المساعد بالخلفية عند تسجيل الدخول.
- Remove_Agent_Autostart.bat: حذف التشغيل التلقائي إذا رغبت.
- Start_Agent.bat: تشغيل المساعد بضغطة واحدة بعد تثبيت مهمة التشغيل التلقائي.
- Stop_Agent.bat: إيقاف المساعد بالكامل عند نقل المجلد أو صيانة الملفات.
- Run_Local_Agent.bat: تشغيل يدوي احتياطي لإظهار الأخطاء.
- Start_Local_Agent_Hidden.vbs وStop_Local_Agent_Hidden.vbs: أدوات احتياطية قديمة.
- worker.js وindex.html: ملفات الواجهة المستضافة على Cloudflare.

المتطلبات:
- Windows
- Python 3 مع المشغّل py وpythonw.exe
- FFmpeg متاح عبر PATH أو في أحد المسارات المعروفة داخل الملف.

ملاحظات:
- هذه مهمة مجدولة لمستخدم Windows الحالي، ولا تحتاج صلاحيات مسؤول عادةً.
- يجب إبقاء مجلد المشروع في مكان ثابت بعد التثبيت؛ إذا نقلته، احذف المهمة وثبّت من جديد.
- المساعد يستمع إلى 127.0.0.1 فقط؛ لا يفتح منفذًا للإنترنت.
- قبول Origin/CORS ليس بديلًا كاملًا عن المصادقة ضد البرامج المحلية الخبيثة.
- المتصفح قد يفرض قيودًا على الاتصال بخدمة localhost حسب إعداداته.
- رابط HLS الناتج محلي ويعمل على الجهاز الذي يشغّل المساعد فقط.
- لم يُختبر سكربت تثبيت المهمة المجدولة على جهاز Windows الفعلي؛ إذا فشل، استخدم Run_Local_Agent.bat مؤقتًا وأرسل رسالة الخطأ.


تشغيل وإيقاف يدويان عند الحاجة:
- Start_Agent.bat لتشغيل المساعد.
- Stop_Agent.bat لإيقاف المساعد.
يمكن إنشاء اختصار لكل ملف على سطح المكتب. الإيقاف لا يحذف مهمة التشغيل التلقائي؛ عند تسجيل الدخول التالي سيبدأ المساعد تلقائيًا مجددًا.
